# QuizLive — bộ khởi đầu

Quiz trực tiếp: host nhập chủ đề, AI sinh câu hỏi, người chơi vào bằng mã
phòng, bảng xếp hạng cập nhật sau mỗi câu.

Thư mục này chỉ chứa tài liệu và cấu hình. Toàn bộ code do Claude Code viết,
theo file `QuizLive_Huong_dan.md` đi kèm.

Chạy sau khi đã xây xong:

    ./scripts/start.sh        # Windows: .\scripts\start.ps1

Mở http://localhost:8000
